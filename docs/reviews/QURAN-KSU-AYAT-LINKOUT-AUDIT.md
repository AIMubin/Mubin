# مُبين — تدقيق إضافة إحالات التفسير إلى القارئ المحلي

**النطاق:** إضافات واجهة قارئ Q0.1c داخل مسودة [PR #76](https://github.com/AIMubin/Mubin/pull/76) فوق الفروع غير المدمجة؛ لا دمج على `main` ولا تغيير `VERSION.yaml` ولا نسخ نص تفاسير.

## التحقق من الحدود الأساسية

1. **هوية النص الأصلي:** ما زال نص كل آية من `SourceIndex` المقيد ببايتات مصدره. الإضافة لا تمس القراءة أو البحث أو SHA-256 ولا تعدل آيات المصدر. تُعرض نصوص القرآن باستخدام `textContent` دون إدراج HTML خارجي.
2. **حد المصدر:** روابط التفسير اختيارية فقط عندما `sourceType` من الأنواع `unverified_github_mirror` أو `tanzil_domain_unattested_export`، والمرجع مطابق لنمط الأرقام المسموح. لا يظهر رابط تفسير مع `synthetic_fixture` أو نوع مجهول، وتظهر رسالة صريحة أن البيانات الاصطناعية ليست آيات.
3. **قيد الرابط:** المضيف والمسار ثابتان `https://quran.ksu.edu.sa/index.php`؛ تُشتق `aya=surah_ayah` من مرجع يعيده محرك مُبين، ورابط التفسير الميسر يستخدم الخيارات الواردة في رابط المستخدم `m=hafs&qaree=husary&trans=ar_mu`. رابط الكتب الأخرى يفتح الآية دون الادعاء بتحديد كتاب مسبقًا، لأن قائمة التفاسير ديناميكية في الموقع.
4. **الخصوصية:** فتح يدوي في تبويب مستقل فقط مع `noopener noreferrer` و`Referrer-Policy=no-referrer`. لا يرسل مُبين استعلامات البحث ولا هوية المستخدم إلى KSU؛ لكن زيارة الموقع الخارجي نفسها تخضع لسياساته وقد تبلّغ عن عنوان IP.
5. **حدود حقوق النشر:** لم يُستورد تفسير أو صوت أو صورة أو بيانات API من KSU؛ لا iframe أو تحميل مسبق أو استخراج نص. مصدر «آيات» يفصح عن أن نص القرآن والتراجم من Tanzil والتفاسير من mosshaf.com، وهو **ليس** اعتمادًا إضافيًا مستقلاً لأصالة النص.
6. **فصل التحليل الآلي:** قسم `ai-explanation` يعلن أنه غير مفعّل؛ لا تشغيل LLM ولا صياغة تفسير ونسبته إلى كتاب، ولا إصدار فتوى أو حكم مستنبط.
7. **الاختبارات:** أضيفت حالات RED مسبقًا في `qa/quran_browser_smoke.py` و`qa/quran_official_chrome_smoke.py`. ثبت فشل Chrome الاصطناعي على التعديل `5739cab465a15ca26d2b1d8990c7c8ec8f540fa4` قبل التنفيذ ([GitHub RED #39200871685](https://github.com/AIMubin/Mubin/actions/runs/39200871685)) مع غياب التمييز المطلوب. ثم نجحت الفحوص بعد إضافة طبقات الواجهة وملف CSS ذي اتجاه RTL في `cc3c14e3be969f3b008e98bede2ca674dd3724eb` ([Chrome #39201099659](https://github.com/AIMubin/Mubin/actions/runs/39201099659)، [Q0.1c #39201099680](https://github.com/AIMubin/Mubin/actions/runs/39201099680)، [P0 #39201099645](https://github.com/AIMubin/Mubin/actions/runs/39201099645)، [مقارنة المصدر #39201099652](https://github.com/AIMubin/Mubin/actions/runs/39201099652)).
8. **دليل التشغيل الحي:** اختبار Chrome على المصدر المباشر يتحقق من رابط الآية `2:1` الكامل وسياسة فتح الروابط وعدم تضمين iframe، ومن عدم تفعيل تحليل AI. اختبار Chrome الاصطناعي يؤكد غياب روابط التفسير المخترعة. لم نتصفح KSU بعد الضغط داخل الاختبار؛ ولذلك تبقى صحة تنقل hash خارجي وحالة التفاسير الحالية خاضعتين لتغير الموقع.

## حالة المراجعة وقرار الدمج

هذه مراجعة هندسية من المشرف، وليست موافقة مراجع خارجي مستقل ولا دراسة علمية لتفاسير الكتب. لم يُجرَ اتصال API مصرح به أو استيراد نص أو تدقيق حقوق محتوى تفسير بعينه. أي تفسير يُنقل مستقبلًا يحتاج سجل `source/edition/rights/verse-span` ومراجعة المواءمة بين الرواية والآية. التحليل الآلي يحتاج قواعد إسناد منفصلة؛ لا تُستخدم هذه الواجهة لترقية ادعاءات الأحكام الشرعية.

الحالة: **وظيفة إحالة خارجية منجزة على فرع PR #76 فقط؛ غير مدمجة؛ مع بقاء القارئ بحثيًا**. سيُحتفَظ بالسجل المركزي خارج GitHub في `/Mubin/PROJECT_STATUS.md`.
