# Q0.1e — تدقيق القارئ المباشر المثبت ببصمة Tanzil

**التاريخ:** 2026-10-18. **الموضع:** [PR #76](https://github.com/AIMubin/Mubin/pull/76) مسودة، غير مدمجة. **إصدار النظام:** `0.1.0-alpha` دون تغيير.

## التنفيذ والفصل بين الصلاحيات

- المسار: Q0.1c قارئ محلي ← Q0.1d مقارنة نصوص المرآة بتنزيل نطاق Tanzil ← Q0.1e جلب الاستجابة المحددة واستخدامها في القارئ. لا طلب دمج جديد ولا تغيير لبيانات الحديث المجمدة.
- يستخدم العميل طريقة GET حصريًا عبر HTTPS إلى `https://tanzil.net/pub/download/index.php` بإعدادات التنزيل المسجلة في `qa/quran_official_probe.PRESET`؛ يحظر إعادة التوجيه ويحد حجم البيانات.
- **SHA-256 الدقيق لملف الاستجابة الكامل**: `7f30c647331a61100ebf24a80507dc0fcdd9f2df97f1312b5b2dfcb982a7f326`. إذا اختلف أي بايت، يفشل تشغيل القارئ قبل الفهرسة؛ لا يتم تطبيع النص أو تصحيح العلامات.
- التحقق البنيوي: 114 سورة، 6236 آية بالترقيم الكوفي، وتسلسل مفاتيح فريد، ووجود إشعار المصدر الأصلي `PLEASE DO NOT REMOVE`. تقارير الاستعلام تعرض النص الأصلي، والبحث دون تشكيل يؤثر على المطابقة فقط.
- يستعيد خادم Q0.1c فهرس البيانات من **البايتات المثبتة نفسها** قبل فتح المنفذ، ويقارنها بفهرس المستدعي لتفادي تزوير النص أو بيانات المصدر؛ metadata غير قابلة لتعديل حقولها بعد التحميل. القارئ يعمل على `127.0.0.1` فقط، بواجهات GET دون كتابة.
- النص القرآني لا يُخزَّن داخل Git ولا artifacts ولا سجلات الاختبارات. البايتات محفوظة في ذاكرة العملية، وإشعار الحقوق المعروض مشتق من ملف المصدر الأصلي دون إعادة صياغة.
- جميع التقارير تحتفظ بـ`source_authenticated=false`، `rights_verified=false` و`eligible_for_religious_ruling=false`. HTTPS وبصمة الملف ليسا توقيعًا للناشر ولا شهادة شرعية أو قرار إتاحة للنشر العام.

## القيود وقرار الدمج

- لا يوجد توقيع رقمي مستقل يثبت أصل البايتات من الناشر؛ سجل HTTPS وبصمة الملف يثبتان هذه الاستجابة والتماثل مع الرصد السابق فقط. أي تغير في إصدار Tanzil يفشل قيد SHA ولا يُتبنى آليًا.
- شروط [Tanzil Text License](https://tanzil.net/docs/Text_License) تقتضي حفظ النص وذكر النسبة وإشعار الحقوق؛ الالتزام البرمجي بالمحافظة على البايتات لا يثبت استيفاء حقوق خدمة نشر عامة مستقبلية.
- اختبار Chrome المصدر الخارجي استشاري بسبب احتمال انقطاع الشبكة؛ لا نستدل على نجاحه من حالة workflow العامة بل من سطر PASS وقد تحققنا منه. ولا تعادل هذه التغطية دراسة سهولة استخدام بشرية أو فحص متصفحات متعددة.
- مراجعة هندسية من المشرف فقط؛ لم يعمل Codex أو مراجع علمي مستقل على هذا الالتزام. لا ادعاء باعتماد مصحف رقمي أو استنباط فقهي.
- تبقى سلسلة PRs #73–#76 غير مدمجة. حماية `main` غير مفعلة عند الفحص الأخير، والتقرير لا يفتح صلاحية دمج تلقائي. مسارات P1 والتفسير والأصول تستمر بالتوازي.

**الخلاصة:** القارئ المحلي أصبح يستخدم استجابة Tanzil المثبتة مباشرة، دون الاعتماد على المرآة عند التشغيل، مع حدود معلنة للسلطة والنشر.
