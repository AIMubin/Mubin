# التدقيق الهندسي Q0.1f — فهرس تفاسير وصفي فقط

**الموضع:** مسودة [PR #76](https://github.com/AIMubin/Mubin/pull/76) في سلسلة القرآن؛ لا دمج ولا رفع للنسخة.

## مراجعة السطح والمخاطر
- يقرأ الخادم ملف سجل ببليوغرافي محلي محدود الحجم (16 KiB)، ويفشل عند الحقول الزائدة أو تكرار مفاتيح JSON أو أي claim بامتلاك النص أو الحقوق أو قبول P1. تحقق `additionalProperties=false` في JSON Schema ومدقق Python القيم المحجوزة؛ رفض التكرار/الترتيب يتم في Python.
- لا يصل القارئ إلى KSU لإحضار تفسير، ولا يطبّع نصه، ولا يضيف آراء LLM أو ينسب تفسيرًا إلى مؤلف على أنه اقتباس. أسماء الكتب والهويات الوصفية قابلة للتوسع بعد بحث مستقل في الطبعات والمصادر.
- تقبل واجهة HTTP سجل المصدر الوصفي فقط إذا كانت الآية موجودة بالفعل في محرك القرآن، وكان `source_kind` من ملفات الآيات غير الاصطناعية المسموحة. محاولات بيانات اصطناعية وحالات المصدر المجهول تُرفض.
- لا يملك السجل أي حق admission into P1، والطبعة null و`rights_status=not_verified` دائمًا؛ رابط KSU العام لا يساوي رابط صفحة كتاب محققة ولا إذنًا قانونيًا.
- تُعرض بيانات الكتب كنص عادي باستخدام `textContent`، ولا تسمح API بعناوين خارج المضيف المثبت. الـHTML المنقول أو iframe غير مستخدم.

## القرار
**مُنجز هندسيًا بوصفه اكتشافًا وصفيًا مع مراجعة المشرف فقط، وليس تفسيرًا محققًا أو مؤهلًا علميًا.** لا يُفعّل استخدام النص في المحرك ولا الدمج التلقائي، و`main` غير محمي عند آخر فحص. استمرار تطوير النص والتفسير وP1 ممكن بالتوازي دون انتظار ترخيص كل الكتب؛ الاستيراد والنشر لهما بوابة منفصلة.
