# Q0.1e — قارئ نص Tanzil المباشر ذو البصمة المثبتة (بلا اعتماد رسمي)

**الحالة:** ميزة هندسية على فرع PR #76، دون طلب دمج جديد؛ الإصدار العام 0.1.0-alpha كما هو.

## التشغيل المحلي

يشغّل الأمر التالي اتصال HTTPS واحدًا إلى صفحة تنزيل Tanzil، وفق إعدادات المصدر المسجلة بتاريخ 2026-10-18، ثم يقارن الملف **بالبصمة الكاملة الثابتة** 7f30c647331a61100ebf24a80507dc0fcdd9f2df97f1312b5b2dfcb982a7f326 قبل فهرسة 6,236 آية. لا يبدأ الخادم إذا تغيّر أي بايت، أو غاب إشعار الحقوق، أو اختل ترقيم الآيات.

\`\`\`bash
python -m engines.quran.q01e --port 8765
\`\`\`

ثم افتح \`http://127.0.0.1:8765/\` على الجهاز نفسه. الخادم يربط \`127.0.0.1\` حصريًا، ولا يكتب نص القرآن إلى Git أو ملف محلي أو سجل أو artifact. تبقى البايتات الأصلية في ذاكرة العملية، ويُعرض النص الأصلي كما استُلم عبر واجهة Q0.1c بوساطة \`textContent\` وباتجاه \`rtl\`. لا تُغيّر علامات الرسم أو الوقف أو التشكيل؛ خيار تجاهل التشكيل يؤثر في المقارنة عند البحث فقط.

## حدود الثقة القانونية والعلمية

نجح مسبقًا في [GitHub Actions #39155112593](https://github.com/AIMubin/Mubin/actions/runs/39155112593) تنزيل الملف من نطاق \`tanzil.net\` ومقابلته بمرآة GitHub؛ **6,236 نص آية متطابقة** مع اختلاف بايتات الملف الكامل. هذه الوحدة تقبل **فقط** تلك البايتات المثبتة، بما فيها إشعار Tanzil؛ ولا تفسر التطابق بوصفه توقيعًا رقميًا من الناشر أو إذنًا مطلقًا للنشر. جميع تقارير القارئ تحتفظ بـ\`source_authenticated=false\` و\`rights_verified=false\` و\`eligible_for_religious_ruling=false\`.

إذا غيّر المصدر نسخة التنزيل أو إعداداته، يتوقف البرنامج بدل تحميل نسخة مجهولة. بوابة تغيير المصدر تتطلب إصدار manifest وبصمة واختبارات ومقارنة جديدة **من دون تعديل النص القديم**. لا تدمج هذه المرحلة التفسير أو الفقه أو الحديث، ولا تمنح أي حكم شرعي.
