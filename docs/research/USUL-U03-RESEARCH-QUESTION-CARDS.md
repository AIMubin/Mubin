**مرحلة أصول داخلية، لا إصدار مُبين العام.** تعتمد على U0.2 في PR #67 وU0.1 في PR #66. هذه البطاقات **أسئلة أنشأها باحث** وليست عبارات ثابتة للشافعي ولا قواعد شرعية محكّمة.

الروابط **مسارات موقع** لا إثبات صفحات من طبعة محققة. عنوان «باب الإجماع» مسجل في U0.2 بوصفه عنوانًا مضافًا من المحقق، لا نصًا متحقق النسبة للمؤلف.

## حدود الثقة

- `source_docket_sha256` يربط هذه البطاقات بمحتوى **سجل U0.2 الوصفي الممرر** فقط؛ لا يشهد على صحة الطبعة أو وجود النص أو حقوق استخدامه.
- `core/usul/claims.py` يتحقق من صحة السجل الأم، وربط هوية كل بطاقة بمعرّف المرشح ومساره وموضوعه ونسبة عنوانه، وترتيب البوابات الست.
- البوابات: مقابلة الطبعة المستقلة، نسبة المؤلف/المحقق، أساس الاستعمال، توثيق المنهج والخلاف، الشروط والموانع والأمثلة المضادة، مراجعتان علميتان بشريتان مستقلتان. **جميعها `not_completed`.**
- علامة الاستفهام العربية شرط صياغي سطحي؛ لا تثبت حياد السؤال أو صحة افتراضاته. لا تُعد بصمة JSON توقيعًا أو اعتمادًا للحقوق.
- لا تحميل كتب، ولا تخريج حديث، ولا وصول إلى H3.9.2 holdouts، ولا نصوص من الكتب، ولا AST أصولي عملي، ولا حكم أو فتوى. نتائج `reviewed_rule_count=0` و`eligible_for_engine=false` ثابتة حتى مع المدخلات الصحيحة.

## إعادة التحقق

```bash
python -m pip install -r core/requirements-test.txt
python -m unittest discover -s core/tests -v
python -m core.usul.claims_cli research/usul/u03-risala-hypothesis-cards.json research/usul/u02-risala-source-candidates.json --json
```

CLI: الرمز 0 = اتساق وصفي فقط؛ 1 = رفض بيانات؛ 2 = ملف/JSON غير صالح. بوابة الاعتماد العلمي وتحرير نصوص الطبعة ليست ضمن U0.3.
