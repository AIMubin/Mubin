# U0.2 — سجل مواضع «الرسالة» للبحث الأصولي

**مرحلة داخلية تجريبية، ليست إصدارًا للنظام كله.** تعتمد هذه المرحلة على U0.1 (PR #66)؛ طلب الدمج الخاص بها PR #67 مبني على فرع U0.1 غير المدمج.

## الغرض وحدود الادعاء

يربط سجل `research/usul/u02-risala-source-candidates.json` أربعة أسئلة بحثية بمواضع **يشير إليها موقع المكتبة الشاملة** في كتاب `8180`، *الرسالة* للشافعي، تحقيق أحمد محمد شاكر، بحسب البيانات المعروضة في الموقع. هذه **بيانات رصد وفهرسة** وليست نصًا محققًا أو ترخيصًا للنسخ أو حكمًا أصوليًا معتمدًا.

| المرشح | الموضوع | رابط الموقع | الصفحة المطبوعة التي يعرضها الموقع |
| --- | --- | --- | ---: |
| `u02_c001` | العام والخصوص | https://shamela.ws/book/8180/146 | 53 |
| `u02_c002` | عام الظاهر والخصوص | https://shamela.ws/book/8180/149 | 56 |
| `u02_c003` | تخصيص العام بالسنة | https://shamela.ws/book/8180/157 | 64 |
| `u02_c004` | الإجماع | https://shamela.ws/book/8180/556 | 471 |

**ملاحظة النسبة:** تشير الملاحظات التحريرية المسجلة إلى أن عنوان «باب الإجماع» أُثبت بعمل المحقق من النسخ المطبوعة، ولا يجوز اعتباره تلقائيًا عبارة للشافعي. نحتفظ بالحالة `heading_authorship=not_verified_authorial` لجميع المرشحات. رقم نهاية رابط الموقع **ليس** رقم صفحة الطبعة المطبوعة. مطابقة الطبعة المطبوعة نفسها لم تُنجز بعد.

## الضمانات البرمجية

- **أربعة مرشحات ثابتة:** كل `candidate_id` مرتبط بموضوع محدد و`route_id`؛ لا يجوز إعادة تسمية أو تبديل المواضع بصمت.
- مخطط JSON 2020-12 يحظر حقول النصوص والحواشي المنسوخة، والحقوق المزعومة، والموافقات الوهمية، وقواعد AST التنفيذية.
- مدقق `core/usul/docket.py` يرفض الهوية المزورة، والحقول الخفية، وتكرار المعرفات والروابط، والقيم غير الصالحة والأنواع المخصصة التي قد تزوّر المقارنة.
- `core/usul/docket_cli.py` يستعمل قارئ U0.1 المقيد (ملفات محلية عادية فقط؛ رفض تكرار مفاتيح JSON والرموز العددية غير القياسية والروابط الرمزية والملفات الخاصة). **لا يُجري أي طلبات شبكة**.
- `docket_sha256` يعرّف بيانات **السجل الوصفي فقط**؛ ليس بصمة لنص الكتاب أو سندًا للترخيص.
- مهما كانت سلامة السجل، يبقى `verified_rule_count=0`, `eligible_for_engine=false`, `rights_verified=false`, `edition_authenticated=false`, `source_bytes_available=false` و`scholarly_authority_verified=false`.

## إعادة الاختبار

```bash
python -m pip install -r core/requirements-test.txt
python -m unittest discover -s core/tests -v
python -m core.usul.docket_cli research/usul/u02-risala-source-candidates.json --json
```

## شروط الترقية البحثية اللاحقة

إثبات نسخة الطبعة بمصدر مستقل مسموح الاستخدام؛ مطابقة نسب العناوين والحواشي والمتن؛ تحرير صياغة القاعدة وشروطها واستثناءاتها وخلافها؛ مراجعة مختصين مستقلين موثقة أدلتهم؛ فصل كامل عن H3.9.2 holdouts وعن U0.1 synthetic rules حتى يجري بناء عقد أدلة موثق.

**النتيجة الحالية:** أربعة مواضع قيد البحث، صفر قواعد فقهية/أصولية محكّمة، لا نصوص كتب مستوردة، ولا صلاحية للاستنباط الآلي.
