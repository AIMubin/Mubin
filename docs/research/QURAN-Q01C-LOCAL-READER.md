# Q0.1c — واجهة محلية للقراءة والبحث (Quran reader vertical slice)

**الحالة:** مسودة هندسية مقيَّدة على PR #75 فوق Q0.1b #74 وQ0.1 #73. الإصدار العام `0.1.0-alpha` دون تغيير. لا يعد هذا نشرًا رسميًا لمصحف رقمي أو اعتمادًا لنصه.

## الوظيفة المنجزة

تسمح الواجهة المحلية باستخدام ملف `Q0.1b` الذي **يحضر المستخدم بايتاته بنفسه** مع manifest مطابق مثبت SHA-256 وGit blob عند استعمال مرآة acfatah. لا يتصل هذا التطبيق بأي مصدر لتنزيل النص، ولا ينسخه إلى GitHub أو يعيد إنشاء ملف قرآن معدلًا. يُفتح على `http://127.0.0.1:8765/` حصريًا. واجهة عربية باتجاه RTL لعرض `sura:ayah` والبحث الحرفي والبحث المتسامح مع حركات العربية في **المقارنة** فقط؛ النص المعروض هو نفس سلسلة Unicode الواردة في الملف الأصلي.

المسارات محدودة: `/` و`/reader.js` و`/reader.css` ثم `/api/status` و`/api/get?ref=2%3A1` و`/api/find?q=...&mode=folded&limit=20` و`/api/notice`. ولا توجد نقاط كتابة أو تعديل أو تنزيل الملف كاملًا. تخضع المدخلات لحدود طول وعدد بارامترات، ويرفض النظام التكرار والتراكيب الخطرة ورؤوس Host/Origin الخارجية مع CSP وnosniff وno-store. يعرض نص الآيات عبر DOM `textContent` حصريًا، دون `innerHTML` أو حقن HTML. نتائج العينات الاصطناعية تُعرض بعلامة واضحة «ليست آية».

## التشغيل

تحتاج نسخة محلية من الملف **بحالته الأصلية** ودون إعادة حفظ أو تعديل، وملف manifest الأصلي في فرع Q0.1b.

```bash
python -m engines.quran.q01c \
  --manifest engines/quran/q01b/sources/tanzil-mirror-v1.1.json \
  --source /private/path/to/original-quran-uthmani.txt \
  --port 8765
```

افتح في المتصفح `http://127.0.0.1:8765/`. لا حاجة لمكتبات ويب، أو مفاتيح ذكاء اصطناعي، أو مزود خارجي. خيار `--bind` غير موجود أصلًا حتى لا تتحول خدمة البحث إلى مضيف عام دون سياسة نشر وحقوق وهوية نسخة واضحة.

## مصدر النص وحدود الصحة والحقوق

- النص الكامل الذي نجح Q0.1b في قراءته جاء من **مرآة GitHub غير رسمية** [acfatah/tanzil](https://github.com/acfatah/tanzil)، مقيّدة بالالتزام `052b515f3a24dfacbe4cafc3b89f0681a447f462` والبصمة `f64fe7657dbe2e185e9995e14f7a67ee6cf1a30773f39184883d7a763d70fb19`، وليس من مصدر Tanzil المضبوط مباشرةً.
- الوثيقة الرسمية [Tanzil Text License](https://tanzil.net/docs/Text_License) تشترط حفظ النص دون تغيير، ونسبة النص بوضوح إلى Tanzil وربط صفحته وحفظ إشعار الحقوق مع النسخ. واجهتنا توفر رابطًا واضحًا وتعرض **إشعار المصدر من الملف نفسه** دون تفسير أو حذف، لكن هذا لا يعني إتمام كل المتطلبات القانونية لكل حالة استخدام.
- [تنزيل Tanzil الرسمي](https://tanzil.net/pub/download/index.php) يتطلب تثبيت نوع النص وإعدادات العلامات والوقف والسجدة والبسملة؛ الاختلاف بين إعدادات التنزيل قد يجعل مقارنة SHA-256 مباشرة غير صالحة حتى لو كان المحتوى مشروعًا. لم نثبت أن المرآة مطابقة بايتًا بايتًا لإعداد رسمي بعينه، وقد تختلف إشعارات النسخ المنشورة بحسب تاريخ الإصدار.
- يعلن البرنامج دائمًا `source_authenticated=false` و`rights_verified=false` و`eligible_for_religious_ruling=false`. الصحة الرقمية للمحتوى مقارنة ببصمة في manifest **لا** تعني التوثيق من الناشر، ولا تصديق القراءة أو التفسير أو صلاحية الاستنباط الفقهي.

## تسريع المشروع دون اختناقات

تستقل واجهة Q0.1c عن P1 وR3 وأحكام الحديث؛ يمكن اختبار UX والاستعلام وحماية مصدر البيانات على ملف اصطناعي أو مرآة بحثية محليًا الآن. يبقى مسار المقابلة الرسمي مستقلًا: يحضر مشرف المصدر تنزيل Tanzil الأصلي ببصمة وإعدادات موثقة، ويقارن البايتات دون تعديل؛ إذا اختلفت البصمتان فتُسجل `not_equivalent` لا تُوحّد النسختان آليًا.

**ما لم ينجز:** مصحف رسمي موثق للنشر العام، واجهة نشر عامة، استضافة عامة، ربط تفسير معتمد، مدقق أحكام، أو مراجعة بشرية مستقلة. كل ذلك يأتي بعقود وإثباتات منفصلة ولا يعطل تطوير تجربة القراءة المحلية.

التشغيل: `python -m unittest discover -s core/tests -v`.
