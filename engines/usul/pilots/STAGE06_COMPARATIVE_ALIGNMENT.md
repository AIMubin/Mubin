## What has been built

[Witness alignment engine](../witness_alignment.py) verifies two independently pinned UTF-8 **section files**, indexes every strict character edit with byte spans, source line numbers and changed-span hashes, and outputs NO source text. It reports four distinct comparison profiles: exact bytes, Arabic combining marks and square bracket delimiters ignored (never bracket contents), collapsed whitespace, and removed whitespace. The latter is a **word-boundary candidate**, not certified lexical identity. None of these profiles assert meaning preservation. Arabic marks can change meaning; negation, hamza/alef and words inside editorial brackets remain material differences.

[Stage06 al-Waraqat runner](waraqat_stage06.py) verifies BOTH frozen original HTML SHA-256 digests, reproduces W1 UTF-8 extraction from its original HTML, checks W1 section bytes against the frozen Stage04 receipt, and requires the W2 section to match an independently supplied SHA-256. Without the strict secondary replay option, the runner **does not prove that the W2 section was extracted from the W2 HTML**, so it returns STAGE06_TEXT_ALIGNMENT_PROVENANCE_PARTIAL. With --require-secondary-extraction, the separate versioned [candidate W2 HTML extractor](waraqat_witness2_extract.py) must reproduce the W2 section bytes exactly from the pinned W2 HTML, or the run is refused. A successful strict replay returns STAGE06_DUAL_SOURCE_EXTRACTION_REPLAY_PASS (byte reproducibility only, not authorial/edition/semantic identity).

[Comparator tests](../tests/test_witness_alignment.py) and [pinned source tests](../tests/test_waraqat_stage06.py) exercise original-byte anchors, reproducibility, residual textual changes, negation and diacritics, tamper detection, and missing private files.

    $d = "D:\MubinSources\waraqat"
    $raw = [System.IO.File]::ReadAllBytes("$d\waraqat-private-utf8.txt")
    if ($raw.Length -ne 16410) { throw "Wrong Stage04 W1 snapshot length" }

    if ((Get-FileHash "$d\waraqat-bab-amr-private.txt" -Algorithm SHA256).Hash.ToLowerInvariant() -ne "20879bade7a4a831a0020e1bae51806ca015d7803be42fdb44e580a9055581ab") { throw "W1 section altered" }

Archive the generated bytes and an independently pinned section digest/locator. Do **not** assume the output matches earlier operator-extracted W2 text: check its exact hash and diff before adopting this versioned conversion. The W1 extractor does not support the W2 markup.

Missing private files yield PENDING_PRIVATE_WITNESS_FILES (exit 3).

This verifies only fidelity to **this deterministic extractor**. Editorial boundaries and any skipped HTML elements remain part of extractor-validation scope.
