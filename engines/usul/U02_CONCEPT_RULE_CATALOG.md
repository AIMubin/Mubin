# U0.2 pilot 01 — candidate concept/rule index (research-only)

**Internal Usul U0.2 development slice, not an operational qualified engine.**
Mubin remains `0.1.0-alpha`. The U0.1 executor, P0 Rule/Evidence/
Methodology contracts and Stage08/09 provenance utilities are unchanged.

## Purpose and deliberate boundary

U0.1 already contains one-step propositional simulations, structural
P0→spec bindings and Stage08 byte-scoped lexical research navigation.
This pilot only adds an explicitly **unassessed, typed, machine-checkable
candidate index** to help organize subsequent methodological research.
It does not reinterpret or execute source text.

`concept_rule_catalog.py` accepts:

- `concepts`: ID, proposal role (`TERM|CONDITION|EXCEPTION|OUTCOME`),
  `review_status=UNASSESSED`. No excerpts or prose definitions.
- `rule_candidates`: `if_concepts`, `unless_concepts`,
  `then_concept`, and `pointer_id` referring to an existing
  **unassessed RULE_RESEARCH_POINTER** in a pinned Stage08 graph.
- `relations`: `PROPOSED_RELATED_TO`, `PROPOSED_BROADER_THAN`,
  or `PROPOSED_DISTINGUISHED_FROM`, all `UNASSESSED`.

All manifest fields are bounded and strictly typed. Unrecognized keys,
missing concept references, duplicate/reused links, cycles in proposed
broader-than relations, and attempts to insert a `qiyas` or scholarly
verification field are refused.

The caller supplies a trusted `stage08_graph_sha256` **from outside
the input graph**. The module reconstructs Stage08's canonical hash,
then follows `RESEARCH_NAVIGATION_ONLY` pointer → query → pinned
section links. The stored section hash is a provenance reference only:
**a lexical match cannot authenticate a rule, exception, semantic equivalence,
or fatwa.**

A successful status `U02_CANDIDATE_CATALOG_PASS` means the candidate
structure and references have passed deterministic syntactic checks.
It does **not** mean the source is authentic, a rule is valid, or a
juristic conclusion may be derived. The module never touches P0 execution,
does not consume confidential witness text, and forces all scholarly,
semantic, redistribution, support and authorization flags to false.

## Tests / synthetic integration

```bash
python -m unittest discover -s engines/usul/tests -v
```

`test_concept_rule_catalog.py` constructs a synthetic Stage08-shaped
metadata fixture for boundary/adversarial checks and independently
generates an actual Stage07→Stage08 graph from a **temporary synthetic
Arabic source** in its integration test.

To produce a catalog from an independently pinned Stage08 output:

```bash
python -m engines.usul.concept_rule_catalog \
  --stage08-graph /private/reviewed/stage08-graph.json \
  --trusted-stage08-sha256 <INDEPENDENT_FULL_64_HEX_PIN> \
  --manifest engines/usul/examples/u02-candidate-catalog-demo.json \
  --out /private/reviewed/u02-catalog.json
```

The sample manifest uses `pointer:real`, the pointer ID generated by
the synthetic integration test. Replace it with an actual Stage08
research pointer ID before using any other graph. Do not use a hash
copied from a newly generated untrusted graph as external attestation.
CLI exit 0 means structurally accepted; exit 2 means a rejected contract.
The output contains **metadata IDs and hashes only**, not source text.
