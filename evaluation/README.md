# Evaluation

Cross-engine evaluation and system release gates belong here; Hadith H3.9.2 qualification remains independent.

P0 tests cover only structural graph integrity and fail-closed trace requirements. In P1–P7 measure external source correspondence, faithful encoding of scholarly rules, actual rule execution and precedent agreement separately. Use frozen source/family-disjoint tests, objections and abstentions. A machine-only test is **never** independent human review.

Engine engineering and evaluation do not require blanket scholarly signoff. Distinguish trace checks, source correspondence, rights, rule execution, and externally approved authoritative conclusions; see [risk-based assurance](../docs/RISK_BASED_ASSURANCE.md). Frozen H3.9.2 human-labeled benchmark gates are not affected.
